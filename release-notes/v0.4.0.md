> 从本版本起，风灵月影宗支持应用内自更新。

## 🚀 程序内更新

- 「设置 → 软件更新」一键检查新版本；启动时也会静默检查（可在设置中关闭，绝不自动下载）
- 发现新版本后可在应用内直接下载，支持暂停 / 继续 / 停止与断点续传，中途关闭应用重开也能接着下
- 下载完成后自动做 sha512 完整性校验，通过才会进入安装环节；安装前有确认弹窗
- 更新包来自 GitHub Releases 官方发布页；便携版用户仍引导前往发布页手动更新

## 其他改进

- 昼夜双主题界面定稿，换新应用图标
- 「最近更新」刷新时保留原有列表，加载状态改由按钮特效表达，不再闪空白
- 修复关闭窗口时下载状态监听器未解绑导致的内存泄漏

## 下载说明

- **安装版**：`FlingTrainer-Manager-Setup-0.4.0.exe`（推荐；旧版本用户可在应用内直接升级）
- **便携版**：`FlingTrainer-Manager-0.4.0-win.zip`（解压即用；更新请下载新版覆盖或前往发布页）
